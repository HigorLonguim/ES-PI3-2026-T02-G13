# Projeto MesclaInvest - PI3 2026

## Descrição
O MesclaInvest é um aplicativo móvel desenvolvido para a disciplina de Projeto Integrador 3. Ele simula um ambiente de investimento em startups por meio de tokens digitais. O sistema permite visualizar startups, consultar documentos e realizar operações simuladas de compra e venda.

## Tecnologias
* **Frontend:** Flutter & Dart
* **Backend:** Node.js & TypeScript
* **Banco de Dados:** Firebase Firestore
* **Gestão:** GitHub Projects

## Como Executar
### Backend
1. Entre na pasta `/backend`
2. Instale as dependências: `npm install`
3. Inicie o servidor: `npm run dev`

### Frontend
1. Entre na pasta `/frontend`
2. Obtenha os pacotes: `flutter pub get`
3. Execute o app: `flutter run`
